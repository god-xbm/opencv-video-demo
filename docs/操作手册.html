三、你要做的：5 次双击

第一步永远是同一个动作：打开文件资源管理器，在地址栏粘贴下面这行，回车。

D:\cv-hw\dist

你会看到 5 个黄色齿轮图标的 .bat 文件，编号 1 到 5。按编号顺序，一个一个双击。

1

测「图片模式 + 鼠标取色」

双击：1-图片取色.bat

会先弹出一个黑色命令行窗口（打印文字），紧接着弹出一个图片窗口，画面是三个大方块：红、绿、蓝，每块上面写着 SAMPLE。

你要点哪里、应该看到什么

鼠标左键点这块区域黑窗口里应该打印
最左边的红色方块（靠内一点，避开中间白字）点击坐标: (X, Y) B=0 G=0 R=255
中间的绿色方块（同样避开白字）点击坐标: (X, Y) B=0 G=255 R=0
最右边的蓝色方块点击坐标: (X, Y) B=255 G=0 R=0
方块下面的深灰色空白背景B=40 G=40 R=40（三个数一样就说明取色准）
关键判据：点红色块必须是 B=0 G=0 R=255。如果 R 和 B 搞反了（点红块显示 B=255 R=0），说明程序把通道顺序搞错了 —— 告诉我，我改。
顺序永远是 B、G、R，不是 R、G、B，这是 OpenCV 的约定，也是题目的隐含考点。

怎么退出

先用鼠标点一下图片窗口（让它获得焦点），然后随便按键盘上一个键。图片窗口关闭，黑窗口会显示 退出码 = 0，再按回车关闭黑窗口。

看不到图片窗口？黑窗口里如果出现「宽度 640 / 高度 480」这几行，说明图已经读进来了，只是窗口可能在别的屏幕或最小化了 —— 用 Alt + Tab 找一下。
2

测「真实照片」（对应题目：换一张图再测）

双击：2-图片模式-照片.bat

这次打开的是 Windows 自带的风景壁纸（1920 × 1200 的 JPG），不是程序画出来的图。这是题目明确要求的「用另一张图片再测一遍」。

黑窗口应显示：宽度 1920 像素 / 高度 1200 像素 / 通道数 3（三通道 BGR 彩色图）
按键退出，退出码 0。
3

测「视频模式 + Esc 提前退出」

双击：3-视频模式-720p.bat

会弹出一个视频窗口，自动开始播放。左边有一个橙黄色方块往右跑，下面一个蓝圆上下摆 —— 肉眼就能看出有没有卡帧。

画面左上角应该有三行字

Frame : 当前帧号 / 180
Size : 1280 x 720
FPS : 10 ~ 60 之间的数（随机器性能变）
这一项要你亲手做：视频是全屏播放的，用鼠标左键点一下视频画面（给它焦点），画面会暂停住 —— 然后按键盘左上角的 Esc 键。
黑窗口应打印：用户按 Esc 提前退出，退出码 0。
这是题目 35 分里「按 Esc 可提前退出」那一条，只能由你按键验证。
注意：不按 Esc 也行，视频 6 秒播完会自己结束、也会打印「视频播放结束」。两种退出方式各试一次最好——先跑一遍让它自己播完，再跑一遍按 Esc。

跑完去看结果文件

地址栏粘贴 D:\cv-hw\dist\output 回车，会看到一个 motion.mp4。双击用系统播放器打开，确认：能播、尺寸是 1280×720、左上角的三行字和时间同步、帧号一直在涨。

4

测「另一段视频」（对应题目：换一段视频再测）

双击：4-视频模式-小视频.bat

这段是 640×480、25fps、125 帧、AVI 格式，和上一段的分辨率、帧率、容器全都不同 —— 用来证明代码没有写死某一个文件。

屏显应为：Size 640 x 480，Frame 从 1 涨到 125。
产物：output\motion2.mp4（输入是 avi，输出统一转成 mp4，尺寸保持一致）。
5

测「错误提示」（这一项不弹窗，纯看文字）

双击：5-错误提示演示.bat

它会自动跑 4 种错误情况，每种都会打印中文提示和一个退出码。照着核对：

情况提示文字（大意）退出码
[A] 一个参数都不给参数个数不正确 + 打印用法2
[B] 图片文件不存在找不到输入文件 + 当前工作目录 + 提示相对/绝对路径3

五、万一出现问题，先看这张表

现象原因与处理
双击 bat，黑窗口一闪就没 通常是 exe 启动失败（缺 DLL）。告诉我，我检查 dist 里的依赖。正常情况黑窗口会停住不关。
黑窗口报「找不到 qt6 平台插件」或窗口不出现 Qt 的 platforms\qwindows.dll 没被找到。检查 D:\cv-hw\dist\platforms\ 里有没有 qwindows.dll，没有我补。
点色块，打印的 X, Y 和实际位置差很多 说明窗口被 Windows 缩放了（DPI 缩放 ≠ 100%）。这是显示层问题，我会改为按窗口内容区坐标换算。
点鼠标完全没反应、黑窗口不打印任何东西 窗口没拿到焦点。先点一下图片窗口的标题栏再点画面。如果还是不动，是回调没挂上，我排查。
视频窗口卡住不动 / FPS 显示 0.0 首帧还没处理完（第一次跑常见），等 1~2 秒。一直不动说明解码器问题，告诉我。
按 Esc 没退出，反而窗口关了 Esc 是 OpenCV 的 waitKey 返回 27。如果窗口焦点在命令行而不是视频窗口，按键不会传给视频窗口 —— 必须先点一下视频画面。
双击 bat 提示「Windows 已保护你的电脑」 不是病毒，是 SmartScreen 对未签名 bat 的默认提示。点「更多信息」→「仍要运行」。

六、交作业时交哪些文件

方案 A（推荐，最稳）：把整个 D:\cv-hw 文件夹压缩提交。约 280 MB（大头是 dist\ 里那 153 个 DLL 和 build\）。老师解压就能双击跑，不用装任何环境。

方案 B（体积小，但要老师自己配环境）：只交源码，打包时排除 build\ 和 dist\，压缩后约 9 MB。老师需要自己有 MSYS2 + OpenCV。

必须包含的文件

CMakeLists.txt ← 构建入口，15 分里明文要求
CMakePresets.json ← VS Code 一键配置用
README.md ← 环境/编译/运行/已知问题
include\ ← 7 个头文件
src\ ← 8 个 .cpp（含 main.cpp）
assets\ ← 2 张图 + 3 段视频（测试素材）
output\ ← 2 份处理成品，证明跑通了
docs\讲解.html ← 代码讲解，可当设计说明交
dist\ ← 方案 A 才需要，自包含可运行包
交之前务必确认一件事：如果老师要求「必须能在他的电脑上编译」，就用方案 B，并且把 README 里那段「OpenCV 5.0 会拒绝 find_package(OpenCV 4 ...)」的说明留着 —— 那是真实的坑，老师换机器编译时很可能踩到，写清楚反而是加分项。
